# Image-Averager
This tool lets you put in multiple images and it will put out an average between the images. 
This works by checking each pixel and then finding the average colors between the two through a color wheel and outputing a new image file to download.

The versions are labeled V=version fisrt number=major update second number= CSS update 3rd number=Bug fixes.
